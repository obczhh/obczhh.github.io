CFM后端渗透上传shell

日常冲浪发现一个CFM后端的站点，通过FUZZ找到文件上传接口，然后开始测试，发现无法上传文件，会报错，报错内容如下：

文件上传功能被服务器端黑名单拦截

The MIME type or the Extension of the uploaded file cfm was not accepted by the server.
并且列出了被阻止的扩展名列表：AS,ASP,ASPX,BIN,DMG,CFC,CFM,CFML,CFR,CFSWF,EXE,HBXML,JSP,JSPX,JWS,MXML,PHP,SWC,SWS

想办法绕过

查看请求包，发现

POST /blog/admin/filemanager.cfm?dir=%2F HTTP/2

dir参数为路径，拼接文件名，查看回显，发现上传成功

POST /blog/admin/filemanager.cfm?dir=%2F3.cfm HTTP/2

能正常访问，然后构造cfm的一句话木马

使用AI生成多个木马，发现无法执行，会报错

然后能执行cmd命令的，也会被cf的WAF拦截，再次尝试绕过

构造本地执行bat文件，然后保存至txt文件中的木马，然后再次上传，成功
